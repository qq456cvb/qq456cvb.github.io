Overview

From a single image to an editable CAD program

A CAD model is a program: a sequence of discrete commands (lines, arcs, circles, extrusions), each with continuous numbers (coordinates, angles, distances). Predicting both from pixels at once is hard. Img2CAD splits the job: a finetuned Llama 3.2 vision-language model writes the program's structure, naming each part, and TrAssembler, a transformer flow-matching model, fills in the numbers.

CAD programs

A CAD model is a short program

Img2CAD uses the sketch-and-extrude language of tools such as Fusion 360 and OpenCascade. A sketch is a closed loop of lines L: (x, y), arcs A: (x, y, α) and circles R: (x, y, r). An extrusion E turns it into a solid: three angles and an origin place the sketch, the last number is the distance, and the extrusion either joins the model or cuts it. Try it on a chair: the buttons change the program's structure, the sliders only change numbers.

Method

    
Structure from a VLM, numbers from a flow model

    
One model predicting a whole program mixes a combinatorial problem (which parts, which commands) with a continuous one (where, how big). Img2CAD conditionally factorizes it: the structure comes first, and the numbers are predicted given the structure.

    
    
      
  1. StructureA finetuned Llama 3.2 reads the image and writes each part's name and command types, with placeholders instead of numbers.
    2. 
      
  2. Shared part namesNames such as backrest or leg stay consistent across shapes, so numbers can be learned across chairs whose structures differ.
    3. 
      
  3. TrAssemblerPart transformers read DINOv2 image features; a global transformer relates the parts, with CLIP embeddings of their names; decoders output every number.
    4. 
      
  4. Flow matching + symmetryNumbers are sampled from noise with GMFlow. At test time each step is nudged toward the mirror or rotational symmetry that GPT-4o reads off the image.

Ablations

    
What each part of the design adds

    
Starting from Llama 3.2 predicting the full program, we add components one at a time; all variants after (i) use the VLM's structure. Semantic part labels and flow matching bring the largest gains; symmetry guidance mostly improves connectivity (fewer disconnected pieces, #SCC) and symmetry (SymChamfer), reported averaged over categories.

    

      

        

        

      

      

      

    

    
  






  

    
Generalization

    
Any viewpoint, and real photos

    
Trained on renders from a frontal viewpoint, Img2CAD stays accurate on renders from random viewpoints, thanks to the view-robust features of Llama, DINOv2 and CLIP. Averaged over the three categories, frontal → random view:

Real photos

    
Although TrAssembler is trained only on synthetic, CAD-ified ShapeNet models, Img2CAD also handles real images: indoor photos from Pix3D and product photos of furniture found online.

    
    

      
      
Why it transfers
The structure comes from a VLM trained on web-scale data, and TrAssembler sees the image through DINOv2 and the part names through CLIP. None of these depend on ShapeNet's rendering style, so real photos, with clutter, lighting and occlusion, still produce clean CAD programs.

    

  






  

    
Editing

    
Edit the CAD model with words

    
The output is a readable program with named parts, so a language model can edit it. Img2CAD recovers the program from a photo; GPT-4o is then asked for a change. “Turn it into a round table” changes the structure: the tabletop and shelf sketches go from lines to circles. “Make it longer” changes numbers, and GPT-4o moves the legs along with the tabletop. Try similar edits on the chair above.

Limitations

    
Where it still fails

    

      
      
    
        
  • Structure errors. Llama 3.2 sometimes misses or invents parts. With the ground-truth structure instead, Chamfer distance drops from 0.1174 to 0.1032.
    • 
        
  • Rare shapes. TrAssembler can misplace parts on complex, long-tail designs.
    • 
        
  • Soft symmetry. Symmetry guidance nudges the numbers, so symmetry and connectivity improve but are not guaranteed.
    • 
        
  • Speed. Sampling with 32 Euler steps takes about 5 seconds per shape.
    •

Abstract

    

      Read the full abstract
      
Reverse engineering 3D computer-aided design (CAD) models from images is an important task for many downstream applications including interactive editing, manufacturing, architecture, robotics, etc. The difficulty of the task lies in vast representational disparities between the CAD output and the image input. CAD models are precise, programmatic constructs that involves sequential operations combining discrete command structure with continuous attributes – making it challenging to learn and optimize in an end-to-end fashion. Concurrently, input images introduce inherent challenges such as photometric variability and sensor noise, complicating the reverse engineering process. In this work, we introduce a novel approach that conditionally factorizes the task into two sub-problems. First, we leverage vision-language foundation models (VLMs), a finetuned Llama3.2, to predict the global discrete base structure with semantic information. Second, we propose TrAssembler that conditioned on the discrete structure with semantics predicts the continuous attribute values. To support the training of our TrAssembler, we further constructed an annotated CAD dataset of common objects from ShapeNet. Putting all together, our approach and data demonstrate significant first steps towards CAD-ifying images in the wild.
